# 2026-05-21 工作日志

## 重构 login_screen.dart

### 第一轮：基础重构
- 消除硬编码颜色（Color(0xFF...)），改用 Theme ColorScheme
- 提取 `_inputDecoration()` 方法，消除 3 个输入框的重复 InputDecoration 代码
- 提取 `_LoginCard` 私有 StatelessWidget，分离 UI 与状态逻辑
- 改进错误处理：`_callLoginApi` 根据异常关键词给出友好中文提示
- 修复 lint：`throw` 字符串改为 `throw Exception(...)`（only_throw_errors 规则）
- 增加 `errorBorder` 到 InputDecoration

### 第二轮：拆分为可复用小组件（同文件）
拆分为 4 个独立私有组件，提升可复用性：
- `_LoginHeader`：图标 + 标题，可复用在任何登录/欢迎页
- `_LoginTextField`：统一 InputDecoration 样式，支持 label/icon/obscure/onSubmitted
- `_LoginButton`：提交按钮 + loading 状态，通用「提交+loading」场景
- `_ErrorMessage`：错误提示文字，统一样式
- `_LoginCard`：组合以上组件，构建完整登录卡片
- `_LoginScreenState`：仅负责状态和登录逻辑，不关心 UI 细节

### 第三轮：拆分为独立文件
用户要求将小组件拆成独立文件，完成以下拆分：
- `lib/core/widgets/login_header.dart` → `LoginHeader`
- `lib/core/widgets/login_text_field.dart` → `LoginTextField`
- `lib/core/widgets/submit_button.dart` → `SubmitButton`（通用提交按钮，不只用于登录）
- `lib/core/widgets/error_message.dart` → `ErrorMessage`
- `lib/core/widgets/login_card.dart` → `LoginCard`（组合以上组件）
- `lib/core/screens/login_screen.dart` → 仅保留 `LoginScreen` + `_LoginScreenState`，UI 全部改为 import

注意：Dart 下划线私有类仅 library-private，拆到独立文件必须去掉下划线改为 public。

### 第四轮：修复 import 格式 + 启用 lint 规则
- `login_card.dart` 内部 import 改为 `package:` 格式
- `analysis_options.yaml` 启用 `always_use_package_imports: true`，强制 lib/ 内 import 使用 package: 格式
- IDE 报错时执行 `Ctrl+Shift+P → Dart: Restart Analysis Server` 刷新缓存
