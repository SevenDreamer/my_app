## 优先级

| 优先级 | 项目 | 原因 |
|--------|------|------|
| P0 | 酒吧系统功能完善 | 已有较多代码，最快可交付 |
| P0 | 数据库管理功能完善 | 已有较多代码，实用价值高 |
| P1 | Rust FFI 完整集成 | 为性能敏感功能打基础 |
| P1 | 聊天助手 | AI 功能核心，用户价值高 |
| P2 | 设置页面 | 提升整体体验 |
| P2 | 自动更新 | 长期维护必需 |
| P3 | 跨平台适配 | 扩大用户范围 |
