# 落地路线图

## Phase 1：单机 Agent（主手机）

**目标**：主手机上跑一个能调 LLM API 的 Agent，有完整的聊天界面

### 里程碑

- [ ] Flutter 项目基础架构搭建
  - [ ] Riverpod 状态管理
  - [ ] GoRouter 路由
  - [ ] Dio 网络层
  - [ ] 项目目录结构
- [ ] Rust Agent Core 集成
  - [ ] flutter_rust_bridge 配置
  - [ ] Rust 侧 LLM API 客户端（reqwest）
  - [ ] Dart ↔ Rust 双向通信
- [ ] 聊天界面
  - [ ] 消息列表 + 输入框
  - [ ] 流式输出（SSE / WebSocket）
  - [ ] 对话历史本地持久化
- [ ] Agent 记忆系统
  - [ ] 对话上下文管理
  - [ ] 向量库 + RAG 检索增强

**预计耗时**：2-3 周

---

## Phase 2：手机操控能力

**目标**：Agent 能感知和控制手机

### 里程碑

- [ ] Android 系统集成
  - [ ] 打开 App（Intent）
  - [ ] 文件读写
  - [ ] 通知发送
  - [ ] 定位获取
- [ ] Android 无障碍服务
  - [ ] 屏幕内容读取
  - [ ] UI 控件树解析
  - [ ] 模拟点击/滑动
- [ ] 权限管理
  - [ ] L0-L4 权限层级
  - [ ] 用户授权界面
- [ ] 前台服务保活
  - [ ] flutter_foreground_task 集成
  - [ ] WakeLock 管理
  - [ ] 电池优化白名单引导

**预计耗时**：3-4 周

---

## Phase 3：副手机 + 本地模型

**目标**：副手机作为独立 Agent 节点，本地跑小模型

### 里程碑

- [ ] 本地模型推理
  - [ ] llama.cpp 集成到 Rust Core
  - [ ] Qwen3 4B Q4_K_M 模型打包
  - [ ] 模型下载/管理界面
- [ ] 双模型路由
  - [ ] 本地模型：简单问答、意图分类、紧急度判断
  - [ ] 云端 LLM：复杂推理、长上下文
  - [ ] 自动切换策略
- [ ] 副手机极简 UI
  - [ ] 状态面板（在线时长、任务数、内存）
  - [ ] 前台服务控制开关
  - [ ] 无界面模式（纯后台运行）

**预计耗时**：3-4 周

---

## Phase 4：多 Agent 协作

**目标**：两个 Agent 通过中继服务器自主交互

### 里程碑

- [ ] 中继服务器
  - [ ] 消息路由（Rust 实现）
  - [ ] 离线消息队列
  - [ ] Agent 状态同步（在线/离线/忙碌）
  - [ ] 推送触发（FCM / APNs）
- [ ] A2A 协议实现
  - [ ] Agent 发现与注册
  - [ ] 能力协商
  - [ ] 任务委派与结果回传
- [ ] Agent 间协作场景
  - [ ] 信息查询（Alpha 问 Beta 副手机状态）
  - [ ] 文件传输（Alpha 让 Beta 传文件）
  - [ ] 任务执行（Alpha 让 Beta 执行操作）
  - [ ] 知识同步（记忆/技能库同步）

**预计耗时**：4-6 周

---

## Phase 5：自学习进化

**目标**：Agent 在交互中持续进化

### 里程碑

- [ ] 记忆进化
  - [ ] 交互数据 → 向量化 → RAG 检索增强
  - [ ] 定期总结压缩（对话 → 结构化知识）
  - [ ] 用户偏好自动学习
- [ ] 技能进化
  - [ ] 交互模式 → 自动生成 Skill 规则
  - [ ] 技能库版本管理
  - [ ] Agent 间技能共享
- [ ] 模型进化
  - [ ] 交互数据上传到服务器
  - [ ] 服务器 LoRA 微调
  - [ ] 微调后模型下发给手机
  - [ ] 本地模型热更新

**预计耗时**：6-8 周
