# my_app

个人工具箱（Flutter，移动优先、桌面互补）——设备互联、手柄控制、Hermes、DSH 系统、
DSH 对话、虚拟屏、组件库、机器人眼睛、Live2D 看板娘、记事本等。

- 愿景与路线：`docs/VISION.md` / `docs/ROADMAP.md`
- 视觉规范：`DESIGN.md`（视觉唯一来源）
- 更新分发：Cloudflare R2 manifest 免授权分发 + Shorebird 热更 + Sentry 远程诊断
- 自动化链路：`docs/AUTO_UPDATE_CHAIN.md`（后台巡检通知 · 一键自动测试 · 自动修复闭环）
